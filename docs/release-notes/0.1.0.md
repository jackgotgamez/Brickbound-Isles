# Brickbound Isles 0.1.0

First playable single-player release.

## Included

- Third-person movement, camera orbit, and jumping on one continuous starter island.
- Procedural village, forest, shoreline, paths, rocks, and beacon.
- Trees that break after three hits and drop five collectible timber pieces.
- Mira's “Timber for the Trail” mission, worth 100 points and 10 Imagination Tokens.
- HUD, three achievements, automatic local saves, and progress restoration after relaunch.
- Universal macOS app with an ARM64 Apple Silicon slice, packaged as a disk image.

## Install note

This build is ad-hoc signed but not notarized or signed under a Brickbound Isles Developer ID. Gatekeeper may still warn on first launch. Control-click **Brickbound Isles.app** in Finder and choose **Open**. If needed, open it once and use **System Settings → Privacy & Security → Open Anyway**. Install it in Applications before first launch.
